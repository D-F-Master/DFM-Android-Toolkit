# YL Utils — 主题设计体系

> 本文件提炼自 `App_Utils.vue`（ADB 工具）和 `App_PortTool.vue`（端口工具）的统一样式。
> 新增功能页面时，遵循此体系即可保持视觉一致。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **卡片驱动** | 每个功能区块是一张 `.card`，有层次地堆叠在灰色背景上 |
| **绿色主调** | `#4caf50` 为主色，用于主按钮、活跃状态、图标 |
| **8px 基准** | 所有圆角、内边距、间距使用 8px / 16px 倍数体系 |
| **微动效** | 按钮悬浮上移 2px，阴影加深，过渡 `0.35s cubic-bezier(0.16, 1, 0.3, 1)` |
| **暗色优先** | 必须覆盖 `@media (prefers-color-scheme: dark)` |

---

## 2. 布局结构

每个功能页面的标准 HTML 骨架：

```html
<div class="app">
  <button class="back-button" @click="goHome">&lt;</button>
  <main>
    <div class="container">
      <div class="content">
        <!-- 页面内容：卡片堆叠 -->
        <div class="card">
          <div class="card-header">
            <span class="card-icon"><!-- SVG 图标 --></span>
            <span>标题</span>
          </div>
          <div class="card-body">
            <!-- 内容 -->
          </div>
        </div>
      </div>
    </div>
  </main>
</div>
```

如果左侧需要侧边栏（如 ADB 工具的设备列表），在 `.container` 内先放 `.sidebar` 再放 `.content`。

## 4. 暗色模式

所有样式必须提供 `@media (prefers-color-scheme: dark)` 覆盖。核心映射表：

| 亮色 | 暗色 |
|------|------|
| 页面背景 `#f0f2f5` | `#1a1d23` |
| 卡片背景 `#fff` | `#2d2f36` |
| 表头背景 `#fafafa` | `#33363e` |
| 分割线 `#f0f0f0` | `#40434a` |
| 主要文字 `#333` | `#e0e0e0` |
| 次要文字 `#888/999` | `#999` |
| 输入框背景 `#fff` | `#3a3d45` |
| 输入框边框 `#ddd` | `#555` |
| 绿色主色 `#4caf50` | `#66bb6a`（保持可读性） |

完整示例见 `App_PortTool.vue` 的 `@media (prefers-color-scheme: dark)` 区块。

## 6. 快速开始 —— 新增功能页面的步骤

1. **复制模板结构**：从 `App_PortTool.vue` 复制 `<template>` 骨架
2. **使用卡片容器**：
   ```html
   <div class="card">
     <div class="card-header">
       <span class="card-icon"><!-- 选一个 SVG 图标 --></span>
       <span>页面标题</span>
     </div>
     <div class="card-body">
       <!-- 你的内容 -->
     </div>
   </div>
   ```
3. **按钮选层级**：
   - 主要操作 → `<button class="check-button">`
   - 次要操作 → `<button class="quick-scan-button">`
   - 危险操作 → `<button class="kill-button">`
4. **加入暗色模式**：在 `<style scoped>` 末尾加上 `@media (prefers-color-scheme: dark)` 覆盖
5. **终端验证**：运行 `npm run build`，确认无错误
